# 法考工作台(本地 Web UI)

把 CLI 操作搬到网页:逐题训练、分析报告、竹马导入、题库浏览、档案与模考。

## 安装与启动

```bash
pip3 install -r 09_导入与处理工具/web/requirements.txt   # 仅 Flask
./fakao ui                                              # http://127.0.0.1:7800
```

核心 CLI 保持零第三方依赖;Flask 只是可选的 UI 组件,不装也不影响 `./fakao` 其他命令。

## 页面

| 页面 | 说明 |
|---|---|
| 概览 `/` | 今日待复测、题库统计、任务列表 |
| 逐题训练 `/train` | 服务端判分,答案不经网络下发;答错/低信心追问错因;支持中断续做 |
| 分析报告 `/reports` | 提分指标、模考走势、错误聚类、分科诊断,可一键重新生成 |
| 题库浏览 `/bank` | 按科目/状态筛选;详情含答案与作答历史 |
| 档案与模考 `/profile` | 写入用户档案与学习合同;模考成绩 append |
| 竹马导入 `/zhuma` | 两阶段:打开浏览器→你登录→点"我已登录"后台导出;任务互斥、可取消 |

## 架构

```
浏览器(Jinja + Tailwind) ── Flask(views/) ── bridge.py(唯一封装层) ── fakao_cli.py
                                                └─ tasks.py(竹马后台进程) ── 竹马脚本
```

- 业务逻辑全部在 `fakao_cli.py`,Web 层不重写;`bridge.py` 是唯一 import CLI 的地方
- 训练会话落盘 `05_训练记录/训练会话状态.json`,关页面/重启服务都能续做
- 训练接口对题目做字段白名单投影(剥离答案),判分在服务端完成

## 已知边界

- 单用户 localhost 场景:无鉴权、无 CSRF;不要暴露到公网
- 不建议网页与 CLI 同时记录作答(写操作有锁串行化,但为避免混淆,同一时间用一边)
- 竹马导出时长无上界(分页随机间隔);取消会终止子进程
- 本目录代码会被提交;模板与静态资源中不得放真实题目、凭据或个人数据
