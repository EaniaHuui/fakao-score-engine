# Fakao Score Engine

这是一个以提高法考成绩为唯一目标的本地 AI 训练系统。它把你自己的真题、错题、笔记和课程资料，变成今天该做的专项训练和后续复测。

它不是文件存放处，不是题库分发仓库，也不承诺押题。它的工作是把资料输入、规则提炼、逐题训练和作答记录连成一条链，用真实作答数据优先处理最反复、最危险、最可能拉低分数的错误。

## 唯一目标：提分

所有功能都必须服务于正确率、答题速度、稳定性或模拟成绩。为了“看起来完整”而制造题海、长篇总结或无依据预测，没有价值。

## 系统怎么组织

```text
资料输入
01_待导入资料 -> 02_原始资料库

知识与训练
02_原始资料库 -> 03_考点知识库 -> 04_题目训练库

学习管理
00_系统与用户 + 05_训练记录 -> 06_提分任务

模拟与阶段材料
07_模拟考试 + 08_阶段性材料

工具与规则
09_导入与处理工具 + _meta + skills
```

- `01_待导入资料`：刚放入、尚未解析和审核的资料。
- `02_原始资料库`：确认来源后的原文，只读，不被 AI 覆盖。
- `03_考点知识库`：规则、成立条件、例外、易混点和来源。
- `04_题目训练库`：结构化题目、错题和专项题库。
- `05_训练记录`：每次作答的对错、耗时、信心、错因和复测。
- `06_提分任务`：根据当前错误和到期复测动态生成的今日任务。

AI 只有四条硬边界：不改原文；所有规则和解析保留来源与法律版本；无法确认时明确待核验；AI 生成内容默认待审核，不能直接进入正式训练。

## 适合谁

- 你有竹马错题、真题、笔记或课程资料，想把它们变成可执行训练。
- 你不缺资料，缺的是“先补什么、怎么复测、什么时候算真的会”。
- 你愿意使用本地 AI Agent，例如 Codex 或 Claude Code。

如果你没有任何真实错题或真题，系统可以先帮你建立学习档案；但不能据此作出可靠的个性化提分判断。

## 10 分钟开始

### 1. 准备项目和 Agent

克隆本仓库，进入项目目录。如果需要拉取竹马数据需要 Python 3.9+；本地 CLI 不依赖第三方 Python 包。

让你已配置、且能访问当前项目目录的 AI Agent 读取项目内的 Skill。不同 Agent 的安装和启动方式不同；不要把 API Key、cookie 或个人资料提交到仓库。

### 2. 让 Agent 问诊

在项目根目录对 Agent 说：

```text
/fakao 帮我初始化法考提分系统。
我的目标是提高应试分数。
```

它应先问清考试日期、目标分、最近成绩、每日可用时间、已有资料和主要失分原因。信息确认后，才写入本地用户档案和学习合同。

### 3. 导入自己的错题或真题

优先给它最近的错题。对 Agent 说：

```text
/fakao-importer 帮我导入并检查我的错题或真题。
保留来源、法律版本和审核状态；不要改写原始资料。
```

导入竹马错题时，只需说“帮我导入竹马错题”。浏览器会自动打开；你自己登录、完成验证码后回到终端按回车，系统会自动导入、分析并生成今日任务。不需要提供接口 JSON、cURL、cookie 或 token。

### 4. 拿到今天的提分任务

资料导入后说：

```text
/fakao-training-session 开始今天的逐题训练。
根据我的错题，识别反复错误的错因、考点和题型，生成错误专项训练和今天的任务。
任务要包含原题重做、隔日复测和完成标准。
```

用户不需要写长篇解释。答题时可以只回复 `B C`，表示“选 B，信心低”；如果需要标记错因，再回复第三个选项。高信心且独立答对的题只记录并继续，错误、低信心猜对和历史错题才进入变体与间隔复测。

第一轮验收只看三件事：你反复错在哪里、要做哪些有限题目、今天先做什么。不要把“导入了多少资料”当作进度。

## 它如何工作

```text
真实错题/真题
    -> 导入并保留来源
    -> 按错因、考点、题型和耗时分析
    -> 生成有限的专项训练
    -> 原题重做 + 间隔复测
    -> 新作答记录重新排序
```

项目内 Skill 对应这个过程：

- `fakao`：建立学习档案、时间容量和验收指标。
- `fakao-interaction-protocol`：统一低输入提问、选项和作答格式。
- `fakao-training-session`：逐题出题、追问、反馈、记录和掌握验收。
- `fakao-importer`：导入并审核资料，不覆盖原文。
- `fakao-mistake-diagnostician`：区分不会规则、规则混淆、漏条件、审题、速度和策略问题。
- `fakao-error-attack-coach`：把同类错误转成专项训练和复测。
- `fakao-personalized-bank`：从已确认题目中抽取当前薄弱点的有限题目。
- `fakao-adaptive-planner`：根据新作答记录调整下一轮计划。
- `fakao-update`：更新项目代码和规则，保护用户修改并处理版本冲突。

完整列表见 [skills/README.md](skills/README.md)。AI 生成的法律结论和变体题默认待审核，不能直接当作正式资料。

项目更新时使用 `/fakao-update`。它会先检查本地改动和远端版本；无冲突才合并，冲突则生成报告并等待确认，不会覆盖你的资料或规则。

完整的数据流和对话产物见 [匿名端到端示例](examples/end_to_end_example.md)。

## 目录地图

```text
00_系统与用户       用户档案和学习合同
01_待导入资料       等待解析和审核的资料
02_原始资料库       只读原始真题、错题和课程资料
03_考点知识库       规则、条件、例外和来源
04_题目训练库       结构化题目、错题和专项题库
05_训练记录         作答、错因、耗时和复测结果
06_提分任务         今日任务、错误专项和学习计划
07_模拟考试         套卷、成绩、耗时和复盘
08_阶段性材料       基础、强化和冲刺材料
09_导入与处理工具   CLI、导入和云盘工具
```

目录内的 README 说明各自边界。真实题库、个人资料、训练记录和生成结果默认被 Git 忽略，克隆后由用户在本地创建。

## 一次真实训练

```text
AI：第 1 题 / 今日 6 题。请回复选项 + 信心（A 高 / B 中 / C 低 / D 猜的）。
用户：B C
AI：答案错误。请选择主要原因：A 不会规则  B 规则混淆  C 漏条件  D 审题/陷阱。
用户：C
AI：补充成立条件和例外，标注来源；安排原题重做和隔日变体复测。
```

训练指标见 [fakao-metrics](skills/fakao-metrics/SKILL.md)：只看高频错题复测正确率、陌生变体正确率、平均答题时间、猜对比例和模拟成绩变化。运行 `./fakao metrics` 可生成本地周报；样本不足时不会假装有结论。

## 资料来源

你可以导入 Markdown、PDF、DOCX、笔记或题库文件。Markdown 题目会被尝试解析为待审核的结构化题目；PDF、DOCX 和普通笔记先进入待导入区，经人工或 AI 审核、提取后再进入原始资料库。

竹马和夸克只是把你自己的资料带入本地流程的工具，不是本项目的核心价值。仅使用自己的账号和合法资料，不得把 cookie、token、课程文件、题库原文或导出结果提交到仓库。

## CLI：供 Agent 调用和排查

Skill 负责问诊、判断和解释；CLI 负责稳定地读写本地资料、统计和训练记录。正常使用时，让 Agent 调用 CLI 即可。需要排查时可以手动执行：

```bash
./fakao --help
./fakao init --target-score 108 --daily-minutes 120
./fakao import ./你的资料目录
./fakao zhuma
./fakao error-analysis
./fakao error-attack
./fakao today
./fakao metrics
./fakao mock-record --score 108 --total-questions 100 --seconds 10800
```

记录一次复测：

```bash
./fakao review <题目ID> --result wrong --seconds 90 --confidence low --reason "规则不会"
```
