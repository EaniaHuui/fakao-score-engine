# fakao

## 目标

建立用户的法考提分档案和可执行学习合同。目标不是聊天，而是获得能改变任务排序的事实。

## Web 工作台优先

用户提出以下意图时，不要在对话里手工模拟界面，直接运行 `./fakao ui` 启动本地网页工作台（已在运行则自动弹出到该页面），让用户在网页上完成操作：

- 做题 / 训练 / 复测 / 刷题 → 训练页
- 看报告 / 看指标 / 看错误分析 / 看模考成绩 → 报告页
- 导入竹马错题、浏览题库、填写档案、录入模考成绩

Web 覆盖不了的（法律规则讲解、变体题讲解、学习计划讨论）继续用对话完成。启动后告知用户："工作台已在浏览器打开"。

## 必问信息

- 考试日期、考试阶段、目标分数
- 历史成绩和最近模拟成绩
- 各科基础、已完成课程、已有资料
- 每天真实可用时间和固定限制
- 主要错误类型：不会、记混、漏条件、审题、速度或策略

## 输出

先向用户复述收集到的信息、分数缺口、优先科目、本周目标、每日容量和验收指标；所有推断都要标记依据和置信度，并要求用户确认。

确认后调用 `./fakao init` 写入 `00_系统与用户/用户档案.json` 和 `学习合同.md`。CLI 只写入已经确认的考试日期、目标分数和每日可用时间；其余问诊信息应在用户确认后补充到档案，不能擅自编造。
