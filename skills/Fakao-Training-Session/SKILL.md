# fakao-training-session

## 目标

把一条提分任务执行成真正的逐题训练。目标不是让用户记住原题答案，而是让用户在陌生事实、问法和陷阱下仍能按规则作答。

## 首选载体：Web 工作台

用户要"开始训练 / 做题 / 复测"时，先运行 `./fakao ui` 打开训练页（`/train`），网页已实现本 Skill 的核心交互：逐题作答、选项+信心、自动判分、错因四选一、间隔复测排期、中断续做。引导用户在网页完成训练，AI 负责网页做不了的：训练前讲解目标、训练后讲解错题规则、生成变体题。

## 输入

读取 `06_提分任务/今日任务`、`04_题目训练库`、`03_考点知识库`、`05_训练记录` 和 `skills/fakao-interaction-protocol/SKILL.md`。每次出题前读取 `05_训练记录/训练会话状态.json`；每次记录作答后更新当前任务、题目 ID、阶段和下一步，因此中断后从未完成题继续，不重复已完成题。

## 一轮训练流程

1. 展示本轮目标、预计题数和完成标准；一次只出一道题。
2. 优先隐藏答案和解析，要求用户只回复“选项 + 信心”，例如 `B C`。
3. 用户高信心且独立答对时，只记录结果并进入下一道到期题，不追加变体和长解析；保持训练效率。
4. 对低信心、猜题、历史错题或错误答案，追加一个低输入追问：选择错因编号；只有无法归类时才要求自由说明。
5. 对需要强化的题，让用户先说考点、触发条件或解题顺序，再反馈答案。不要先泄露解析。
6. 强化反馈必须覆盖：规则、成立条件、例外、相邻规则、题干识别信号、每个选项的排除理由和来源。
7. 根据错因选择下一动作：主动回忆、原题重做、对比题、同构变体、限时题或隔日复测。
8. 通过 `./fakao review` 保存结果、耗时、信心、来源类型、独立作答状态和错因；不把对话中的临时判断当作正式掌握。

## 一条知识点的掌握链

同一考点必须经过：

```text
规则盲回忆
-> 成立条件/例外
-> 原题重做
-> 选项排除
-> 相邻规则对比
-> 改事实变体
-> 改问法/包装变体
-> 间隔盲测
```

仅对进入强化链的考点执行以下验收；普通高信心正确题不触发整条链。

至少满足以下条件才可标记掌握：

- 能脱离选项说出规则、成立条件和例外；
- 能解释原题每个选项为什么对或错；
- 至少两道未见过的变体题独立答对；
- 间隔复测连续三次答对，且不是低信心猜对；
- 耗时达到该题型目标，或已明确记录为非知识性速度问题。

任何一次复测错误都要回到对应的短步骤，不得只重复整道题。

## 单题交互模板

```text
第 1 题 / 本轮 6 题
考点：<只显示考点名称，不显示答案>
<题干和选项>

请回复：选项字母 + 信心（A 高 / B 中 / C 低 / D 猜的）
```

判定后再问：

```text
你选择这个选项的依据是？
A 记得规则  B 识别到条件  C 排除了其他项  D 猜的
```

## 边界

- 原题和用户合法导入的题目可用于正式训练；AI 变体默认是待审核草稿，只能用于草稿练习，不能替代来源明确的原题或作为法律结论依据。
- 法律结论必须引用导入资料和法律版本；来源不明时标记待核验。
- 不一次展示整套题的答案，不用“看解析”替代用户作答。
