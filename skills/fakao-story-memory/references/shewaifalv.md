# 涉外民事关系法律适用法 · 故事记忆口诀

> 科目包示例。口诀负责"记住"，法条对照负责"说清依据"。

## 口诀全文

### 第一组：民事主体（自然人、法人）

**自然人 = 经常居所地（"跑得了和尚跑不了庙"）**
- 跟人急眼了要讲理，往他老家找 → 适用**经常居所地**法律。
- 例外（**"居无行有行为地"**）：老家（经常居所地）认为他无民事行为能力，但干坏事的地方（行为地）认为他有民事行为能力 → 老家不让找，去行为地找，**按行为地法律**。

**法人 = 登记地 + 主营业地（"登记主营地"）**
- 国外公司分不清地界，只能看登记 → 适用**登记地**法律。
- 老板鸡贼，主营业地和登记地不一致 → **两个地方二选一**都可以。
- **易混点**：这里是**主营业地**，不是**办事机构所在地**——重点区分，别记岔。

### 第二组：委托、代理、信托（"自己找的人，商量着来"）

1. **基础规则 = 意思自治**：委托、代理、信托都是自己找的人，允许双方协议选择适用法律。
2. **没商量时，内外有别**：
   - 代理**内部**关系（被代理人与代理人之间，"哥俩关系好"）→ 看这关系从哪建立 → **代理关系发生地**法律。
   - 代理**外部**关系（与第三人，"就事论事"）→ **代理行为地**法律。
3. **信托 = 财产托管**（拆词记忆：财产 + 托管）→ 没约定时，**信托财产所在地**或**信托关系发生地**，两个二选一。

### 第三组：婚姻家庭（"共居 → 共国 → 行为地"三层放宽）

**核心顺序（必须先记）：共同经常居所地 → 共同国籍国 → 行为地（缔结/办理地）。**
所有婚姻规则都是在这个顺序上做加法或减法。想象"不爱异地恋的人"：先要你在老家附近（共居）→ 放宽一点可异地不可异国（共国）→ 再好一点可私奔（行为地）。

1. **结婚**
   - **结婚手续**（"一张纸"，不重要）→ 单边即可：**一方经常居所地 / 一方国籍国 / 婚姻缔结地**，任一有效。
   - **结婚条件**（"凭什么娶你"）→ 按共居 → 共国 → 缔结地顺序：共同经常居所地 → 无则共同国籍国 → 无则婚姻缔结地。
2. **婚姻存续期间**（没离婚，砍掉"行为地"，只留共居、共国）
   - **人身关系**：关系没法谈条件 → **无意思自治**，按共居 → 共国。
   - **财产关系**：可以谈条件 → **有意思自治**；没约定再按共居 → 共国。
3. **离婚**
   - **诉讼离婚**（撕破脸了）→ **法院地法律**（想去哪起诉就用哪的法律）。
   - **协议离婚**（好说好商量）→ 允许意思自治，但只能**一方经常居所地 / 一方国籍国**二选一；没商量成 → 回到共居 → 共国 → 行为地顺序。

## 口诀 ↔ 法条对照表

| 口诀 | 规则要点 | 法条 |
| --- | --- | --- |
| 自己找的人商量着来 | 委托代理可协议选择适用法律（意思自治） | 第16条第2款 |

### 第三组：婚姻家庭

**总顺序：共同经常居所地 → 共同国籍国 → 行为地（缔结/办理地）**

| 口诀 | 规则要点 | 法条 |
| --- | --- | --- |
| 一张纸不重要（结婚手续） | 符合缔结地 / 一方经常居所地 / 一方国籍国任一 → 有效 | 第22条 |
| 凭什么娶你（结婚条件） | 共同经常居所地 → 共同国籍国 → 婚姻缔结地 | 第21条 |
| 人身关系不谈条件 | 夫妻人身关系 → 共同经常居所地 → 共同国籍国（无意思自治） | 第23条 |
| 财产关系可谈条件 | 夫妻财产关系 → 可协议选择（一方经常居所地/国籍国/主要财产所在地）；未选择 → 共同经常居所地 → 共同国籍国 | 第24条 |
| 撕破脸（诉讼离婚） | 诉讼离婚 → 法院地法律 | 第27条 |
| 好说好商量（协议离婚） | 可协议选择一方经常居所地/国籍国法律；未选择 → 共同经常居所地 → 共同国籍国 → 办理离婚手续机构所在地 | 第26条 |

## 高频易错点

1. **法人是"主营业地"不是"办事机构所在地"**——出题常在这两个概念上挖坑。
2. **结婚手续单边即可、条件才讲顺序**——手续无所谓，条件才层层放宽。
3. **婚姻存续期间没有"行为地"**——只有共居、共国；"行为地"只在结婚（缔结地）和离婚协议未达成（办理机构所在地）时出现。
4. **协议离婚的意思自治只限两选一**（一方经常居所地/一方国籍国），不能随便选第三地。
5. **信托拆词**：财产（财产所在地）+ 托管（信托关系发生地），二选一即可，无需同时满足。
