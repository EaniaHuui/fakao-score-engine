# 法考法条故事记忆法（全科目通用）

## Overview

把枯燥法条变成"有画面、有情绪、有逻辑"的故事，让记忆锚在生活场景上而不是条文序号上。
本技能同时是**方法论**（对任何新法条都能现编口诀）和**内容库**（references/ 下每科目一个成品口诀包）。

## 工作流程

### 第一步：查科目包
用户提到具体科目时，先看 `references/` 是否已有该科目包。有 → 按包授课（教学/复习/答疑三模式见下）。没有 → 进入创作流程。

### 第二步：创作流程（对任意法条现编口诀）

按顺序执行五步，产出结构化口诀：

1. **拆解规则要素**：把法条拆成最小要素——主体（谁）、行为（做什么）、后果（适用哪地/哪国法律）、例外（特殊情况）、顺序（优先级）。多条规则先分组（如"主体组""关系组""程序组"）。
2. **匹配锚点类型**：为每个要素从"锚点类型库"（见下）挑最合适的技法，给规则起"外号"（如"跑得了和尚跑不了庙"）。
3. **编故事串联**：把锚点串成有冲突/因果的小故事，用人物关系、生活场景让要素之间产生逻辑（如"惹事→找老家→老家不认→去事发地"）。
4. **定顺序**：多条规则按优先级用"层层放宽 / 加减法 / 先例外后一般"串成序列，让顺序本身可推（如"共居→共国→行为地"是一级级放宽）。
5. **标易混点**：找出题人爱挖坑的概念区分（如"主营业地 vs 办事机构所在地"），单独列出，作为"高频易错点"。

产出后把成品写入 `references/<科目>.md`（格式见科目包模板），沉淀为内容库。

### 第三步：三模式服务

- **教学模式**：按编好的口诀逐组讲，先抛画面后落规则，每组讲完让用户复述一个锚点。
- **复习模式**：用户给场景/关键词 → 用口诀反向答规则；答错只回讲对应故事锚点。
- **答疑模式**：口诀解释 + 对照科目包里的法条要点核清依据。

## 锚点类型库（六种常用技法）

| 技法 | 做法 | 实例（涉外法） |
| --- | --- | --- |
| 生活冲突 | 把规则安到"跟人急眼/惹事"等冲突场景 | 自然人按经常居所地 = "跑得了和尚跑不了庙" |
| 人物关系 | 用亲疏定义内外/主次 | 代理内部 = "哥俩关系好"（关系发生地）；外部 = "就事论事"（行为地） |
| 拆词联想 | 把术语拆成两个生活词，各对应一条规则 | 信托 = 财产 + 托管 → 财产所在地 / 信托关系发生地 |
| 递进放宽 | 用"条件越好越放宽"串优先级 | 结婚条件：共居（不愿异地）→ 共国（可异地不可异国）→ 行为地（可私奔） |
| 夸张对比 | 用"重要/不重要"制造记忆反差 | 结婚手续 = "一张纸"，不重要，单边即可；条件 = "凭什么娶你"，才讲顺序 |
| 状态判断 | 用情境状态区分适用规则 | 离婚：撕破脸（诉讼）→ 法院地；好商量（协议）→ 意思自治两选一 |
