# fakao-metrics

## 目标

只用能反映提分的指标评估训练，不用资料数量、对话次数或活跃天数冒充进步。

## 展示载体

指标、模考走势、错误聚类和分科诊断在 Web 工作台报告页（`./fakao ui` → `/reports`）可视化呈现，并可一键重新生成。向用户汇报指标时优先打开报告页，再在对话里解读数字含义（如"正确率上升但猜对比例也上升 = 假掌握"）。

## 每周输出

- 高频错题复测正确率：进入强化链的题目，在到期复测中的正确比例。
- 陌生变体正确率：未见过的变体题独立作答正确比例。
- 平均答题时间：按科目和题型比较，避免只追求正确率。
- 猜对比例：正确但低信心或标记“猜的”的比例。
- 模拟成绩变化：最近两次可比模拟的总分和分科变化。

## 解释规则

正确率上升但耗时明显增加，标记为“会但不稳”；正确率不变且猜对比例上升，标记为“假掌握”；原题正确而陌生变体错误，继续训练规则边界。指标必须附样本数和覆盖日期，样本不足时标记“证据不足”。
