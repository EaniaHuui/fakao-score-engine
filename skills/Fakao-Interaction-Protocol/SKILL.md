# Fakao-Interaction-Protocol

## 目标

让用户用最少输入完成问诊、答题和复测，同时保留足够证据判断是否真的掌握。

## 通用规则

1. 先读取已有档案、资料索引和训练记录；能从本地证据得到的内容不再询问用户。
2. 每轮最多询问 1-3 个会改变任务排序或训练方式的问题。
3. 优先使用编号选项；用户可以只回复编号、字母或“同上”。
4. 给出默认判断时标注“请确认”，不要把推断写成用户事实。
5. 一次只要求用户完成一个动作，不同时要求长篇解释、总结和规划。

## 低输入选项

### 学习阶段

`A` 未开始  `B` 基础学习  `C` 完成一轮课程  `D` 刷题强化  `E` 冲刺

### 作答信心

`A` 高  `B` 中  `C` 低  `D` 猜的

### 错因

`A` 不会规则  `B` 规则混淆  `C` 漏条件  `D` 审题/陷阱  `E` 速度/策略  `F` 其他

如果用户选择 `F` 或无法判断，再要求一句话说明；否则不强迫用户写解释。

## 答题输入格式

用户只需回复：

```text
B C
```

含义是“选择 B，信心低”。需要诊断时再补充一个错因编号，例如 `B C C`。

## 输出约束

每次反馈都要区分：用户答案、正确答案、错因、规则、来源、下一步。不得只给标准解析或直接连续展示整套答案。
